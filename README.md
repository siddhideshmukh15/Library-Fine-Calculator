# Library Fine Calculator

## Description
A simple Python-based application that
calculates library fines based on the number of days a book is returned late.

## Features
- Enter book name.
- Enter the number of late days.
- Calculate library fines automatically.
- Apply different fine rates based on late days.
- Display book name, late days, and total fine.
- Menu-driven program.
- Exit option.

## Fine Calculation Rules
- 1–5 days: ₹2 per day
- 6–10 days: ₹5 per day
- Above 10 days: ₹10 per day
- 0 days: No fine
